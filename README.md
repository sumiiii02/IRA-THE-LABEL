# IRA THE LABEL — Store

First frontend build for the IRA THE LABEL online store.

## What is included
- Premium boutique-style storefront
- Responsive navigation
- Home page
- Shop / collection page
- Category filters
- Search
- Wishlist
- Cart
- Empty checkout placeholder
- Owner/Admin dashboard preview
- Product / inventory / order / customer / analytics / settings modules
- Demo products only

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local Vite URL shown in the terminal.

## Important
The products in this first build are placeholders. Replace them only after the brand owner approves the design and supplies real product information.
